# 小红书第一期推广设计：宝爸自用练习纸工具公开

## 目标

用常州学区房账号自然推出家庭练习纸工具，目标不是立刻转化访问，而是涨粉信任：让用户觉得账号从“聊学区房”延伸到“聊买完学区房后的家庭学习节奏”。

## 人设与定位

账号人设是常州宝爸。真实处境是：一边考虑学区房，一边面对孩子每天口算、默写、订正、打印资料等家庭执行问题。

这期不做硬广，不直接挂链接。内容口径是：聊了半个月学区房后，开始说买完之后的真实日常；练习纸工具是宝爸自用顺手后，先免费分享给同样需要的家长。

## 核心观点

学区房解决的是入口，但每天的学习节奏，还是回到家里。

学校重要，老师和班级也重要；但口算、默写、订正、资料打印这些事，最终都发生在饭桌旁。工具的价值是降低家长每天准备练习材料的成本。

## 转化方式

- 卡片中展示一张真实生成的 A4 练习纸。
- 文案中引导评论或私信关键词：`口算`、`默写`。
- 不在卡片正文直接放网址。
- 通过“收藏 + 关注 + 私信关键词”承接工具访问和后续私域。

正文：

```markdown
聊了半个月常州学区房，我越来越觉得：

学校当然重要。

但买完学区房以后，真正每天落到家里的，是口算、默写、订正、打印资料这些小事。

孩子今天要不要练？
练多少合适？
题目从哪里来？
英语按哪个单元默？

这些事情看起来小，但每天都在消耗家长。

所以我自己做了一个练习纸工具。

现在有：
- 1-6年级口算练习
- 英语单词默写
- 五年级分数专项
- 可以直接生成 A4 打印

不是卖课，也不是机构资料。
就是一个宝爸自己用着顺手，先免费分享给同样需要的家长。

想要的可以评论 / 私信：

后面我会按年级慢慢讲，低年级口算、英语默写、分数专项到底怎么安排。
```
